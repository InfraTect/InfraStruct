너의 역할은 현재 뼈대 코드로만 구현되어 있는 CurrentStateStore를 구현하는 것이다.


CurrentStateStore은 InfraStruct에서 CurrentResources로 역직렬화, 그리고 json으로 직렬화를 담당하는 클래스이다.

CurrentResources는 사용자가 정의하고 인프라에 반영이 된 인프라의 상태인에, 테라폼으로 비교하자면 state 파일인가?? 하고 동일한 역할을 한다. 이 파일을 기반으로 현재 상태의 diff를 찾아서 적용하는건데, 이게 중요한건 아니고, 중요한건 파일 상태를 저장할 수 있어야 한다는 것이다.

일단은 파일로 저장하는 형태이고, 테라폼처럼 다른 오브젝트 블록에 저장하는거는 생각하지 않는다.

그래서 너의 역할은 우리의 개발 convention에 따라서 최종적으로는 plan --> spec --> 구현 --> qa/fix --> 문서화 이다.

참고로 plan, spec은 내가 직접 검토하고 피드백을 함. 그래서 plan 작성하고 검토 수정, spec 작성하고 검토 수정 이렇게 진행하고, 구현부터 문서화까지는 너가 스펙 문서에 맞춰서 진행하면 됨.

개발 컨셉은 스펙 주도 개발 + 테스트 드리븐 개발이야. 아마 프로젝트 컨벤션을 보면 알겠지만, given when then이 곧 테스트 코드가 되는거임. 이게 정말 중요해.

그리고 전체 그림은 프로젝트 루트의 InfraStruct.drawio (1).xml을 참고하도록.
